## What I Bring

- Signal-to-system thinking: I connect communication theory, BER simulation, circuit behavior, datasheets and real implementation constraints.
- Firmware and system mindset: I work across device-side C/C++, FPGA/SoC logic, PC-side Python tools and networked workflows.
- Reproducible documentation: I turn lab folders into readable repositories with README files, release notes, reports and traceable artifacts.
- AI-assisted engineering: I use Python, notebooks and applied AI to accelerate testing, automation and computer-vision workflows.
